## 📌 작품 설명 
### P2P 통신을 이용한 요트 다이스

> Java와 IntelliJ를 기반으로 개발한 P2P 통신 기반 요트다이스 게임입니다. <br>
> TCP/IP 소켓 통신을 이용해 사용자 간 직접 연결(P2P)을 구현하고, 실시간으로 주사위 데이터를 주고받을 수 있도록 설계했습니다. <br>
> Java Swing을 활용해 주사위 굴리기, 점수판 등 인터랙티브한 UI를 구성했습니다. <br>
> 네트워크 통신 구조와 이벤트 기반 GUI 프로그래밍을 직접 구현하며, 실시간 멀티플레이 게임 로직 설계 능력을 향상시켰습니다. <br>
